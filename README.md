# 📸 TenantSnap

> Seamless property condition documentation for tenants and landlords.

TenantSnap eliminates deposit disputes and simplifies property walkthroughs. Built for both renters and property managers, it provides structured room-by-room checklists, integrated photo capture, and instant, shareable PDF inspection reports.

---

## 🚀 Key Features

* **Dual-Role Support:** Tailored workflows for both tenants and landlords to maintain transparent, shared records.
* **Room-by-Room Audits:** Complete coverage for walls, floors, doors, windows, fixtures, and appliances.
* **Photo & Note Attachment:** Snap live photos or upload existing images directly to specific checklist items with detailed damage notes.
* **One-Click PDF Reports:** Automatically compile photos, notes, and checklist items into professional, exportable reports.
* **Share Anywhere:** Export directly to PDF or share via email and native device sharing menus.
* **Centralized History:** Access, review, and download all past inspection reports from a single dashboard.
