TenantSnap
TenantSnap is a property condition inspection tool designed for both tenants and landlords to document, track, and verify the state of a rental property. It streamlines move-in, move-out, and routine inspections through guided checklists, photo documentation, and automated PDF reporting.

Key Features
Role-Based Workflows: Built for both tenants and landlords to create transparent, shared property records.

Room-by-Room Checklists: Guided templates to inspect walls, floors, doors, windows, fixtures, appliances, and existing damage.

Rich Media Documentation: Attach high-resolution photos and notes to specific rooms or checklist items.

Automated PDF Reports: Compiles checklists, photos, and timestamps into exportable PDF inspection documents.

Instant Export & Sharing: Download reports directly or share them via email and supported device integrations.

Historical Archive: Dedicated History & Reports dashboard to access and review past inspection records.

How It Works
Start an Inspection: Sign in, select the property, and choose the inspection type (e.g., move-in, routine, move-out).

Conduct the Walkthrough: Complete room checklists, flag damages, add explanatory comments, and capture photos.

Generate & Share: Generate the finalized PDF inspection report for review, downloading, or distribution.
